## 网络架构解析：BGP智能调度与多机房多活容灾

暮光加速的技术特色在于其**Anycast + BGP 动态智能调度系统**。与传统静态绑定服务器入口的机场不同，暮光加速的前置接入网关能够实时感知国内各省各骨干运营商的连接状况：

```
[中国电信/联通/移动/广电用户]
             ↓ (DNS Anycast 智能探测用户地理位置与网络运营商)
[暮光加速全国 8 大 BGP 聚合中心节点]
             ↓ (动态探测：丢包率、RTT 延迟、骨干抖动)
[专线跨境链路池 (香港/日本/新加坡多路 IEPL/BGP 专线出口)]
             ↓ (智能故障自愈，秒级平滑切线)
[海外原生商业 IP 解锁落地节点 (4K 视频 / ChatGPT / 社交多端)]
```

### 1. 跨运营商智能选路（Carrier-Aware Routing）
很多北方联通或南方移动用户在连南方单一入口时延迟飙升。暮光加速在华北（北京）、华东（上海）、华南（广州/深圳）和华西（成都）部署了四组核心 BGP 矩阵，自动将用户路由至距离其最近、延迟最小的接入机房，电信走电信优化、移动走移动 CMI 专线，彻底消除“跨网跨省额外延迟”。

### 2. 毫秒级线路自愈与故障熔断
当某条国际海底光缆出现故障或临时维护时，控制层探针会在 300 毫秒内触发容灾熔断，将用户的流量平滑切往备用专线出口，无需用户手动打开客户端反复测速切换节点。
