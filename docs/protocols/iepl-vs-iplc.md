## 一、物理层与链路层架构：IEPL 与 IPLC 的本质差异

             ┌──────────────────────────────┐┌──────────────────────────────┐

             ├──────────────────────────────┤├──────────────────────────────┤
             │ • 承载层: SDH / SONET 传输网 ││ • 承载层: OTN / 以太网封装   │

## 二、过境原理深度解密：为什么专线能够“永不被封”？

要理解专线的抗封锁机制，必须首先洞察常规公网数据包的过境路径：

### 1. 普通公网（Direct / Transit）的数据流向
普通用户的流量经过家庭宽带发出后，进入国内电信/联通/移动骨干网。跨国时，必须经过部署在北上广深四大国际海缆交换中心的**国际出入口路由器 (International Gateway Routers)**。

在此处，流量必须经过深度报文检测系统（DPI）的层层过滤。一旦检测到特征异常（如 TLS-in-TLS、未放行的 SNI、异常的大吞吐 UDP 流量），防火墙便会主动向双向注入 TCP RST 重置包或执行链路黑洞丢包。

### 2. IEPL / IPLC 专线的数据流向与物理隔离
专线机场的架构则完全不同：

```
 用户设备 ──(家庭宽带)──> [国内 BGP 入口服务器: 深圳/上海/广州]
                                │
                                ▼ (物理光缆/交换机 VLAN 标签划分)
 ┌──────────────────────────────────────────────────────────────┐
 │          中国电信 CTG / 香港电讯盈科 PCCW 跨境专线物理光缆      │
 │                                                              │
 │   • 纯第二层（Layer 2）以太网帧点对点直达，不进入公网路由表    │
 │   • 不经过国际公网海缆交换中心，物理上绕开 GFW DPI 探针       │
 └──────────────────────────────┬───────────────────────────────┘
                                │
                                ▼
         [境外落地机房: 香港 / 日本 / 新加坡 / 美国等核心 PoP]
                                │
                                ▼ (境外原生 BGP 直连)
         Netflix / ChatGPT / YouTube / 跨国办公服务
```

- **二层隔离属性**：IEPL 传输的是带有 802.1Q 标签的以太网数据帧。在传输过程中，数据在深圳机房直接打上专属内网 VLAN 标签，通过中港陆地光缆直接送到香港机房。
- **物理通道独享**：因为该链路属于电信运营商经工信部审批合规备案的大客户跨境电路，其信道属于电信内部专用承载网，根本不接入国际互联网公网出入口，因此天然避开了公网 DPI 检测。

## 三、晚高峰抗 QoS 机制：电信级 SLA 保障

在每天的黄金高峰时段（20:00 至 24:00），国内骨干网与国际公网互联带宽会出现严重的拥堵现象。

### 1. 什么是 QoS（服务质量等级）降级？
当公网国际出口链路拥塞率达到 90% 以上时，运营商的核心路由设备会自动执行 QoS 丢包策略：
- **第一优先级（白名单）**：跨国政企专线、金融结算专网、国际漫游数据（丢包率保护在 0.1% 以内）。
- **第二优先级**：优质公网承载网（如电信 CN2 GIA、联通 9929/CUG）。
- **最末优先级（民用公网）**：普通 163 骨干网与移动 CMI。普通代理用户的数据包在此时会被随机丢弃 10%~40%，表现为网页打不开、油管 4K 疯狂缓冲、游戏疯狂跳 ping。

### 2. IEPL 的 CIR（承载信息速率）硬核保障
正规 IEPL 专线在采购时均附带电信运营商签署的 **SLA（服务等级协议）**，承诺：
- **CIR（Committed Information Rate）= 100%**：无论公网如何堵塞，专线预留的物理带宽管道 24 小时满速畅通。
- **抖动（Jitter）< 2ms**：中港延迟严格锁定在 20ms~25ms 区间，沪日延迟锁定在 25ms~30ms。

这也是为什么经过专业测速的顶级 IEPL 专线在晚高峰能够拉出一条笔直如直尺的测速带宽曲线。

## 四、如何甄别真假专线（鉴别劣质冒牌货的四大实操方法）

由于专线成本高昂（通常千兆企业专线月租高达数万元），市场上存在大量用廉价公网中转冒充“专线”的劣质机场。

<div class="obs-card">
  <div class="obs-header">
    <div class="obs-title">🔍 真假专线鉴别工程手册</div>
    <span class="obs-badge badge-operational">实测防坑指南</span>
  </div>

1. **路由追踪 (Traceroute) 诊断**：
   - 使用包含 MTR 或 BestTrace 的诊断工具测试节点。真专线从国内入口下一跳或两跳直接进入内部局域网 IP（如 `10.x.x.x` 或 `172.16.x.x`），随后直达香港/日本落地机，中间绝不会出现公网省际路由或公网骨干跳数。
2. **晚高峰丢包率持续监控 (Ping Jitter)**：
   - 在 21:00 使用脚本持续向节点发送 1000 个 ICMP/TCP 探测包。真 IEPL 专线的丢包率必定小于 **0.2%** 且延迟波动不超过 3ms；若是假专线，丢包率往往激增至 10% 以上。
3. **敏感时期可用性验证**：
   - 在每年特定敏感保障周期间，公网中转节点会大面积爆红断连，而纯物理 IEPL 专线完全不受任何外部公网策略影响，依然 100% 满速可用。
4. **定价逻辑反推**：
   - 专线物理带宽成本极高。凡是宣传“9.9 元包年 1TB 纯 IPLC 专线”的，100% 是公网中转甚至直连套壳，超售严重，跑路概率极高。
