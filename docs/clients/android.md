## 二、国内定制 ROM 终极后台防杀（保活配置手册）

安卓手机代理频繁断连、息屏后收不到 Telegram 或 Gmail 消息，99% 是由于系统电源管理把代理服务杀掉了。请务必完成以下四步防杀加固：

```
                    ┌──────────────────────────────────┐
                    │      安卓 OEM 系统电源守护进程     │
                    │ (HyperOS / OriginOS / ColorOS)   │
                    └─────────────────┬────────────────┘
                                      │ 息屏定时扫描
                                      ▼
             ┌──────────────────────────────────────────────┐
             │            应用省电策略白名单机制             │
             └───────┬──────────────────────────────┬───────┘
                     │                              │
         未加白名单  │                              │ 已正确配置保活
                     ▼                              ▼
      ┌──────────────────────────┐    ┌───────────────────────────┐
      │  强行清理后台进程 (Kill)   │    │  永驻系统前台服务 (Keep)   │
      │ 代理中断，网络直接瘫痪     │    │  常驻通知栏，毫秒级无感转发 │
      └──────────────────────────┘    └───────────────────────────┘
```

### 1. 锁定后台多任务（加小锁）
- 进入手机多任务切换视图（向上滑动并悬停）。
- 找到代理应用卡片（如 v2rayNG 或 FlClash），长按卡片或向下拉动，点击 **小锁图标 (锁定任务)**。

### 2. 设置电池无限制（白名单）
- 进入系统 **设置** -> **应用管理** -> 找到该代理客户端。
- 进入 **省电策略 / 电池使用**，将默认的“智能后台限制”或“优化”修改为 **无限制 (Don't optimize / No restrictions)**。

### 3. 授予自启动与关联启动权限
- 在应用权限管理中，务必开启 **允许自启动**、**允许后台自启动** 以及 **允许被其他应用唤醒**。

### 4. 开启常驻通知栏提示
- 大多数客户端（如 v2rayNG）设置中有“始终显示通知”。开启后 Android 会将其标记为高优先级前台服务（Foreground Service），极大地提升防杀权重。

## 三、v2rayNG：老牌王者的实战配置与分应用路由

v2rayNG 以极低的学习成本和抗造的稳定性著称：

### 1. 订阅导入流程
1. 打开手机浏览器登录机场后台（如 [光速云](/reviews/guangshiyun)），点击 **复制 V2Ray / VLESS 订阅链接**。
2. 打开 v2rayNG，点击左上角侧边栏 -> **订阅分组设置**。
3. 点击右上角 `+`，填写备注名称（如“光速云专线”），在 `可选地址` 处粘贴订阅 URL，点击右上角保存。
4. 返回主界面，点击右上角三点菜单 -> **更新订阅**，节点池瞬间同步完毕。

### 2. 分应用代理（解决银行/外卖 App 验证失败）
国内很多银行 App（如招商银行、工商银行）、交管 12123 以及部分国服网游，在检测到全局代理时会报错或拒绝登录。
- 打开侧边栏 -> **设置** -> 勾选 **分应用代理**。
- 点击 **选择应用**：将不需要代理的应用（微信、支付宝、网银、美团等）取消勾选，或者采用“仅代理勾选的应用”（如 Chrome、Twitter、YouTube、Telegram 等）。

### 3. 规避 Android 私有 DNS (Private DNS) 冲突
Android 9 及以上版本内置了“私人 DNS (DoT)”功能。若系统 Private DNS 与代理软件的本地 DNS 冲突，会导致整个手机瞬间断网。
- 建议前往系统 **设置** -> **网络和互联网** -> **私人 DNS**，选择 **关闭**，让代理客户端的 DNS 模块全权负责解析。

## 四、FlClash：现代极简派实战

FlClash 是近年来安卓端发展最快的新锐客户端：
1. **纯净无广告**：基于 Google Flutter 开发，UI 动效极其丝滑。
2. **完美支持 Clash 订阅**：直接导入 `.yaml` 订阅或链接，支持按延迟自动测速选点。
3. **策略组直观展现**：节点按国家地区（香港/日本/新加坡/美国）卡片化展示，一键点选即可切换。
