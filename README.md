## 📖 项目简介 (Project Overview)

**机场fun (`jichangtuijian.fun`)** 是一个专注于全球跨境网络加速、专线链路可观测性评测与节点性能监控的技术实验室与知识库系统。

本站坚决摒弃服务商官方宣传软文与商业刷榜，依托部署在中国大陆电信、联通、移动三网真实千兆家用宽带的自动化探测探针，在每晚 **20:00 - 23:00 骨干网最高峰时段** 进行连续高频丢包、抖动、单/多线程吞吐压测，并跟踪全球主流生成式 AI（ChatGPT / Claude / Gemini）与 4K 超高清流媒体（Netflix / Disney+）的底层风控对抗策略。

## 💻 快速开始 (Quick Start)

### 环境依赖
- **Node.js** >= 18.0.0 (推荐 Node.js 20 或 24)
- **包管理器**：npm / pnpm / yarn

### 1. 克隆仓库
```bash
git clone https://github.com/zlzlzl98698-dev/jichangtuijian.fun.git
cd jichangtuijian.fun
```

### 2. 安装依赖
```bash
npm install
```

### 3. 本地开发调试
```bash
npm run dev
```
本地服务将默认启动在：`http://localhost:5173/`

### 4. 生产环境构建
```bash
npm run build
```
编译产物将静态生成至 `docs/.vitepress/dist/`，耗时约 9 秒，可直接部署至 Apache / Nginx / Cloudflare Pages。

### 5. 本地生产预览
```bash
npm run preview
```
本地预览服务启动在：`http://localhost:4173/`
